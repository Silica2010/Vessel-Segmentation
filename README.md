# 实验四：眼底图像血管分割

把 2D 眼底图中的血管区域分割出来，按任务要求输出**血管 = 0、其他区域 = 255** 的二值图。分割时保留视野内的结构信息（视盘、黄斑、血管走行），为后续视杯/视盘分割与图像重建提供一致的解剖约束。对应《深度学习图像分析实验报告》第 5 章。

## 一、任务定义与输出约定

| 项目 | 说明 |
|---|---|
| 输入 | 彩色眼底图（DRIVE / CHASE_DB1 / HRF 等公开数据集） |
| 输出 | 单通道 8 位 PNG，血管 0，其他 255 |
| 评价区域 | 仅统计视野（FOV）内像素，黑边不计入 |

注意输出是**反相**的：通常语义分割用 255 表示前景，本任务相反。`inference.py` 最后一步 `np.where(binary > 0, 0, 255)` 就是这一约定，改动前请先确认下游要求。

## 二、模型结构

带注意力门控的 U-Net：

```
输入 3×H×W（绿通道 + CLAHE）
 ├─ inc(32) →↓ c1(64) →↓ c2(128) →↓ c3(256) →↓ c4(512)      编码，最深 1/16
 ├─ 解码：ConvTranspose 上采样 + 跳跃连接
 │    AG(x4, x3) → [u3, s3] → d3(256)
 │    AG(d3, x2) → [u2, s2] → d2(128)
 │    AG(d2, x1) → [u1, s1] → d1(64)
 └─ outc 1×1 → 单通道 logits（与输入同分辨率）
```

- **只下采样 16 倍**：血管宽度常 1~3 像素，再深一级下采样会把细支抹平。
- **注意力门控**：用粗尺度语义特征生成权重图，压低视盘边缘、黄斑反光等易混淆区域对细血管的干扰，同时保留其下方真实血管。
- **绿通道输入**：血管主要吸收红光，绿通道对比度最高；CLAHE 进一步拉开局部对比。

损失函数：

```
L = BCE(pos_weight=8) + Dice
```

BCE 保证像素级优化稳定，Dice 直接对齐重叠度，单独使用任一在细血管上都不够（前者偏向背景，后者梯度不稳）。

## 四、数据准备

数据不入库。`data/train.csv`、`data/val.csv`、`data/test.csv`：

```csv
image_path,mask_path
images/01_dr.jpg,masks/01_dr.png
```

- 掩膜血管可以是 255 或 1，脚本统一按 `> 127` 二值化；
- 训练按整图缩放至 512，推理在**原分辨率**上做滑窗。

划分建议：DRIVE 官方划分为训练 20 / 测试 20，另从训练集切 4 张做验证，保证同一患者不跨集合。

## 五、训练

```bash
python train.py --train_csv data/train.csv --val_csv data/val.csv \
       --size 512 --batch_size 4 --epochs 80 --lr 1e-4
```

- AdamW + 余弦退火 + AMP；
- 按 **FOV 内 Dice** 选模型与早停（patience 15），因为视野外全是背景，会把指标抬高；
- 几何增强（水平/垂直翻转、±15° 旋转）为主，不做颜色扰动。

## 八、分析要点

- **细血管是主要误差来源**：交叉点与末梢分支在 512 分辨率下被压缩，Dice 的下降几乎全部来自这两处。
- **FOV 内评价的必要性**：不加 FOV 掩膜时 Dice 会虚高 1~2 个点，且无法反映黑边附近的边界错误。
- **反相输出的风险**：若下游代码按“前景=255”读取，会把结果解读反；本仓库在 README 与推理日志中都显式声明了取值。
- **改进方向**：多尺度输入（512+1024 双分辨率融合）、拓扑损失（clDice）约束连通性、以及把血管掩膜作为视盘/视杯分割的结构先验联合训练。
